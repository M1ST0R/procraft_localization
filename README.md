# ProCraft Community Builds

This repository provides two community editions of [ProCraft](https://github.com/artcraft-android/procraft). **This README is navigation only**; detailed instructions and project information live in the linked documents.

## Editions

- **[main — Community Language Packs](https://github.com/M1ST0R/procraft_localization/tree/main):** built-in Russian UI, translation editor, import/export, and integrated community translation catalogue.
- **[russian — Russian Edition](https://github.com/M1ST0R/procraft_localization/tree/russian):** Russian-localized build without the translation editor/catalogue.
